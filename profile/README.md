## 🧠 Overview

Topaz Photo AI is a standalone editor and plug-in that runs several neural models over a photograph: it removes noise, sharpens detail, recovers faces and upscales resolution, deciding which of them the file needs on import.

Published by Topaz Labs. Category: AI photo enhancement.

The archive in this repository contains the desktop application itself plus the integration files for Adobe Photoshop, Adobe Lightroom Classic, Capture One.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🧠 Auto Model Selection | Analyses the image and enables only the models that would improve it. |
| 🌫️ Denoise | Removes luminance and chroma noise from raw and JPEG files with a detail slider. |
| 🔍 Sharpen | Applies deconvolution sharpening without the halos of a simple unsharp mask. |
| 🙂 Face Recovery | Rebuilds detail on faces that are small or soft in the frame. |
| 📈 Upscale | Enlarges the image up to 6x with a model trained per content type. |
| 🎞️ Raw Support | Reads camera raw files directly and keeps the original metadata. |
| 🧩 Plug-in Mode | Returns the result to the host as a layer or a rendered file. |

## 💻 System Requirements

| Component | Minimum / Recommended |
| --- | --- |
| Operating System | Windows 10 64-bit (build 1909 or newer) or Windows 11 |
| Processor | AVX2-capable 64-bit CPU; models run locally |
| Memory | 16 GB RAM minimum, 32 GB recommended for upscaling large files |
| Graphics | GPU with 8 GB VRAM recommended; CPU inference is much slower |
| Display | 1440 x 900 minimum, colour-calibrated display recommended |
| Storage | 10 GB free disk space for the model files |
